Convergence of a sequencemy pick · p.30
A seq. \((s_n)_{n=1}^{\infty}\subset\mathbb{R}\) converges to \(s\in\mathbb{R}\) if \(\forall\,\varepsilon>0,\ \exists\,N(\varepsilon)>0\) s.t. \(n>N(\varepsilon)\Rightarrow |s_n-s|\lt\varepsilon\).
We write \(\lim_{n\to\infty}s_n=s\), \(\lim s_n=s\), \(s_n\to s\).
Order matters: ∀ε first, then ∃N. N is allowed to depend on ε.
Divergence; limit equal to ±∞my pick · p.30
\((s_n)\) diverges if \((s_n)\) doesn't converge to any real number.
We write \(\lim_{n\to\infty}s_n=\infty\) if \(\forall M\in\mathbb{R},\ \exists N>0\) s.t. if \(n>N\Rightarrow s_n>M\).
We write \(\lim_{n\to\infty}s_n=-\infty\) if \(\forall M\in\mathbb{R},\ \exists N>0\) s.t. if \(n>N\Rightarrow s_n\lt M\).
A sequence with limit +∞ still “diverges” (p.33: s_n = n diverges, but lim s_n = ∞).
Supremum and infimummy pick · p.22
Let \(\emptyset\neq S\subset\mathbb{R}\).
\(M_0\in UB(S)\) is the supremum of \(S\) if \(\forall M\in UB(S),\ M_0\le M\). (\(\sup S:=M_0\))
\(m_0\in LB(S)\) is the infimum of \(S\) if \(\forall m\in LB(S),\ m\le m_0\). (\(\inf S:=m_0\))
In words: sup = least upper bound, inf = greatest lower bound. They don't have to be in S. Also p.28: sup S = ∞ if S isn't bounded above, inf S = −∞ if S isn't bounded below.
Upper / lower bound, boundedp.21
Let \(\emptyset\neq S\subset\mathbb{R}\).
\(M\in\mathbb{R}\) is an upper bound of \(S\) if \(\forall s\in S,\ s\le M\).
\(m\in\mathbb{R}\) is a lower bound of \(S\) if \(\forall s\in S,\ m\le s\).
If \(UB(S)\neq\emptyset\), \(S\) is bounded above; if \(LB(S)\neq\emptyset\), \(S\) is bounded below. \(S\) is bounded if \(S\) is bounded above & below.
UB(S) := {upper bounds of S}, LB(S) := {lower bounds of S}.
Max and minp.21
Let \(\emptyset\neq S\subset\mathbb{R}\).
\(s_0\in S\) is the max of \(S\) if \(\forall s\in S,\ s\le s_0\).
\(s_0\in S\) is the min of \(S\) if \(\forall s\in S,\ s_0\le s\).
Key difference from sup/inf: max/min must be elements of S.
Cauchy sequencemy pick · p.58
A seq \((s_n)\subset\mathbb{R}\) is Cauchy if \(\forall\,\varepsilon>0,\ \exists N>0\) s.t. \(m,n>N\Rightarrow|s_m-s_n|\lt\varepsilon\).
No limit appears anywhere in the definition. That's the whole point.
Increasing / decreasing / monotonep.48
A seq \((s_n)\subset\mathbb{R}\) is
increasing if \(s_n\le s_{n+1}\ \forall n\in\mathbb{N}\) (strictly increasing: \(s_n\lt s_{n+1}\)),
decreasing if \(s_n\ge s_{n+1}\ \forall n\in\mathbb{N}\) (strictly decreasing: \(s_n>s_{n+1}\)),
monotone if \((s_n)\) is either increasing or decreasing.
liminf and limsupmy pick · p.53
Let \((s_n)\subset\mathbb{R}\).
For \(N\in\mathbb{N}\), \(u_N:=\inf\{s_n\mid n\ge N\}\), and \(\displaystyle\liminf_{n\to\infty}s_n:=\lim_{N\to\infty}u_N\in\overline{\mathbb{R}}\).
For \(N\in\mathbb{N}\), \(v_N:=\sup\{s_n\mid n\ge N\}\), and \(\displaystyle\limsup_{n\to\infty}s_n:=\lim_{N\to\infty}v_N\in\overline{\mathbb{R}}\).
(u_N) is increasing, (v_N) is decreasing, so both limits always exist in ℝ̄ = ℝ ∪ {±∞}.
Subsequencemy pick · p.61
A subsequence of \((s_n)\subset\mathbb{R}\) has the form \((s_{n_k})_{k=1}^{\infty}\), where \(n_1\lt n_2\lt n_3\lt\cdots\in\mathbb{N}\);
i.e. \(\exists\,\sigma:\mathbb{N}\to\mathbb{N}\) strictly increasing s.t. \(s_{n_k}=s_{\sigma(k)}\).
Remark on the same page: n_k ≥ k for all k (proved by induction).
Subsequential limit, S(sₙ)p.67
\((s_n)\subset\mathbb{R}\). \(t\in\overline{\mathbb{R}}\) is a subsequential limit if \(\exists\,(s_{n_k})\): subseq of \((s_n)\) s.t. \(s_{n_k}\to t\).
\(S(s_n):=\{t\in\overline{\mathbb{R}}\mid t\text{ is a subsequential limit}\}\subset\overline{\mathbb{R}}\).
Sequencep.29
A sequence is a map from \(\{n\in\mathbb{N}\mid n\ge m\}\) (\(m\in\mathbb{Z}\)) to a set \(X\).
Remark: (s_n) and {s_n | n ≥ m} are different. One is the ordered list, the other is the set of values.
Absolute valuep.12
For \(a\in\mathbb{R}\), define \(|a|:=\begin{cases}a,&a\ge 0\\-a,&a\lt 0\end{cases}\)
Axioms you might be asked to statep.02, 07, 25, 26
Peano axiom 5: If \(S\subset\mathbb{N}\) satisfies \(1\in S\), and if \(n\in S\) then \(n+1\in S\), then \(S=\mathbb{N}\).
Well-ordering principle: every \(\emptyset\ne S\subset\mathbb{N}\) has a min, i.e. \(\exists\,s\in S\) s.t. \(\forall t\in S,\ s\le t\).
Completeness Axiom: every \(\emptyset\neq S\subset\mathbb{R}\) that is bounded above has a \(\sup S\) (in \(\mathbb{R}\)), i.e. \(UB(S)\) has a minimum.
Archimedean Property: \(\forall\,a,b>0,\ \exists\,n\in\mathbb{N}\) s.t. \(na>b\).

Theorem toolkit

The results you'll cite by name inside proofs. The blue line says when to reach for each one.

§1–§3 · Numbers

Induction p.02
If \(P(1)\) is true and \(P(n)\Rightarrow P(n+1)\), then \(P(n)\) is true \(\forall n\in\mathbb{N}\).
Any “for all n” formula or inequality.
Rational zeros (monic cor.) p.09–10
If \(r\in\mathbb{Q}\) solves \(r^n+c_{n-1}r^{n-1}+\cdots+c_0=0\) with \(c_i\in\mathbb{Z}\), then \(r\in\mathbb{Z}\) and \(r\mid c_0\).
Proving a number like √2 or √2+√3 is irrational.
Triangle inequality p.12–13
\(|a+b|\le|a|+|b|\), and \(\big||a|-|b|\big|\le|a-b|\).
Every ε-proof. The trick is adding and subtracting: |x| = |x − y + y|.

§4 · Completeness

Completeness Axiom p.25
Nonempty and bounded above ⇒ \(\sup S\) exists in \(\mathbb{R}\). Same for inf when bounded below, via \(\inf S=-\sup(-S)\).
When you need a sup to exist before using it.
Approximation property used p.26, p.49
\(\forall\varepsilon>0,\ \exists\,s\in S\) with \(\sup S-\varepsilon\lt s\le\sup S\). (Otherwise \(\sup S-\varepsilon\) would be a smaller upper bound.)
The “≥” half of any sup/inf equality, and the HW4 #2 construction.
Archimedean p.26
\(\forall\,a,b>0,\ \exists n\in\mathbb{N}\) with \(na>b\). In particular, some \(N\in\mathbb{N}\) has \(N>x\) or \(1/N\lt\varepsilon\).
Justifies “choose N > 5/ε” in ε–N proofs.

§7–§9 · Limits

Uniqueness of limits p.33
If \(s_n\to s\) and \(s_n\to t\) then \(s=t\).
Ruling out a second candidate limit.
Convergent ⇒ bounded p.39
\(\exists M>0\) with \(|s_n|\le M\ \forall n\). The converse fails, e.g. \((-1)^n\).
Inside product proofs; to show divergence of unbounded sequences.
Limit laws p.40–44
Sum, difference, \(ks_n\), product \(s_nt_n\to st\). Quotient: if \(t_n\to t\ne 0\) and \(t_n\neq0\ \forall n\), then \(s_n/t_n\to s/t\).
Computing limits. Always check both quotient conditions out loud.
Order limit p.45–46
\(s_n\le t_n\ \forall n\) ⇒ \(\lim s_n\le\lim t_n\). If \(a\le s_n\le b\) and \(s_n\to s\), then \(a\le s\le b\).
Pinning the limit into an interval so you pick the right root (HW4 #3).
Squeeze p.47
\(a_n\le s_n\le b_n\), \(a_n\to L\), \(b_n\to L\) ⇒ \(s_n\to L\).
Bounding an error term: 0 ≤ |a_n − α| < 2⁻ⁿ.

§10 · Monotone & Cauchy

Monotone Convergence p.48–50
Increasing and bounded above ⇒ converges (to the sup). Decreasing and bounded below ⇒ converges (to the inf). Increasing and unbounded ⇒ \(+\infty\).
Recursive sequences. Gives convergence before you solve for L.
Converges ⟺ liminf = limsup p.55
For \(L\in\overline{\mathbb{R}}\): \(s_n\to L\iff\liminf s_n=\limsup s_n=L\). Always \(\liminf\le\limsup\).
Deciding whether a limit exists in ℝ̄ (HW5 #1).
Completeness of ℝ p.58–60
Convergent ⇒ Cauchy, Cauchy ⇒ bounded, and \((s_n)\) converges ⟺ \((s_n)\) is Cauchy.
Proving convergence when you don't know the limit (HW4 #1).

§11 · Subsequences

Thm 1 p.62
If \(s_n\to L\in\overline{\mathbb{R}}\), every subsequence \(s_{n_k}\to L\).
Passing a limit to a subsequence.
Divergence corollary p.63
Two subsequences tending to different points of \(\overline{\mathbb{R}}\) ⇒ \((s_n)\) diverges.
Every “does it converge? justify” problem with (−1)ⁿ in it.
ε-infinite criterion p.64
Some subsequence \(\to t\) ⟺ \(\forall\varepsilon>0\), \(\{n:|s_n-t|\lt\varepsilon\}\) is infinite. Not bounded above ⟺ some subsequence \(\to+\infty\).
Constructing subsequences one index at a time.
Bolzano–Weierstrass p.65–66
Every sequence has a monotone subsequence (Thm 2), so every bounded sequence has a convergent subsequence.
Existence of a convergent subsequence.
liminf = min S, limsup = max S p.68–70
\(\liminf s_n=\min S(s_n)\), \(\limsup s_n=\max S(s_n)\).
The fast way to compute liminf/limsup: list the subsequential limits.

§12 · liminf / limsup rules

Order p.71
If \(a_n\le b_n\) eventually, then \(\liminf a_n\le\liminf b_n\) and \(\limsup a_n\le\limsup b_n\).
HW5 #2 is a strengthening of this.
Product with a convergent factor p.71–72
If \(a_n\to a>0\): \(\liminf a_nb_n=a\liminf b_n\), \(\limsup a_nb_n=a\limsup b_n\).
Scaling by a positive convergent sequence.
Sum with a convergent term p.73 · red “IMPORTANT for Midterm”
If \(a_n\to a\in\mathbb{R}\): \(\liminf(a_n+b_n)=a+\liminf b_n\), \(\limsup(a_n+b_n)=a+\limsup b_n\).
“periodic sequence + 1/n” problems: the 1/n part drops out (p.74).

Family 1

Induction

HW1 #1, #2, #5 · lecture p.04–05
  1. Name the statement \(P(n)\) explicitly.
  2. Base case: compute LHS and RHS separately and show they agree (or the inequality holds).
  3. Inductive step: “Assume \(P(k)\).” Write the goal \(P(k+1)\) out in full.
  4. Start from \(P(k)\) and do the one natural operation (add the next term, multiply by the next factor), then use algebra to reach the goal.
  5. Close with “By induction, \(P(n)\) holds \(\forall n\).”

TrapIf the statement starts at \(n=4\) (like \(3^n>n^3\)), the base case is \(n=4\) and small cases are checked by hand. Say which cases you checked directly.

Sum of the first n odd squaresHW1 #1

Guess and prove a formula for \(1^2+3^2+\cdots+(2n-1)^2\).

Values for \(n=1,2,3,4\): \(1,10,35,84\). Claim: \(\;1^2+3^2+\cdots+(2n-1)^2=\dfrac{n(2n-1)(2n+1)}{3}.\)

Base case \(n=1\): LHS \(=1\), RHS \(=\frac{1\cdot1\cdot3}{3}=1\).

Inductive step. Assume \(P(n)\). Add \((2n+1)^2\) to both sides:

\[\frac{n(2n-1)(2n+1)}{3}+(2n+1)^2=(2n+1)\cdot\frac{2n^2+5n+3}{3}=\frac{(n+1)(2n+1)(2n+3)}{3},\]

which is \(P(n+1)\) (since \(2(n+1)-1=2n+1\) and \(2(n+1)+1=2n+3\)). By induction the formula holds for all \(n\). ∎

When is 3ⁿ > n³?HW1 #2

Direct checks: \(n=1: 3>1\) ✓. \(n=2: 9>8\) ✓. \(n=3: 27=27\), false. \(n=4: 81>64\) ✓.

Claim: \(3^n>n^3\) for all \(n\ge4\). Base case \(n=4\) is done.

Inductive step (\(n\ge4\)): \(\left(1+\frac1n\right)^3\le\left(\frac54\right)^3=\frac{125}{64}\lt3\), so \((n+1)^3\lt 3n^3\). Then

\[3^{n+1}=3\cdot3^n>3n^3>(n+1)^3.\]

So \(3^n>n^3\iff n\ne3\). ∎

Reverse triangle inequality for n termsHW1 #5

For \(n\ge2\): \(|a_1-a_2-\cdots-a_n|\ge|a_1|-|a_2|-\cdots-|a_n|\).

Lemma (\(n=2\)): \(|a|=|(a-b)+b|\le|a-b|+|b|\), so \(|a-b|\ge|a|-|b|\). This is the base case \(P(2)\).

Inductive step. Let \(S=a_1-a_2-\cdots-a_n\). By the Lemma applied to \(S\) and \(a_{n+1}\): \(|S-a_{n+1}|\ge|S|-|a_{n+1}|\). By \(P(n)\), \(|S|\ge|a_1|-\cdots-|a_n|\). Combining gives \(P(n+1)\). ∎

Family 2

Irrationality via rational zeros

HW1 #3 · lecture p.11
  1. Set \(r=\) the number. Square (and isolate, then square again) until you have a monic integer polynomial with \(p(r)=0\).
  2. By the Corollary of the Rational Zeros Theorem, a rational root must be an integer dividing the constant term.
  3. List those candidates and plug each in; none works. So \(r\notin\mathbb{Q}\).
√2 + √3 is irrationalHW1 #3

Let \(r=\sqrt2+\sqrt3\). Then \(r^2=5+2\sqrt6\), so \(r^2-5=2\sqrt6\). Squaring: \(r^4-10r^2+25=24\), i.e.

\[p(r)=r^4-10r^2+1=0.\]

\(p\) is monic with integer coefficients. If \(r\in\mathbb{Q}\), the Corollary gives \(r\in\mathbb{Z}\) and \(r\mid1\), so \(r=\pm1\). But \(p(\pm1)=1-10+1=-8\ne0\). Contradiction, so \(\sqrt2+\sqrt3\) is irrational. ∎

Family 3

Absolute value and the triangle inequality

HW1 #4, #5
  1. For an “iff”, prove both directions separately and label them (⇒) and (⇐).
  2. Squaring is allowed when both sides are ≥ 0; it turns absolute values into products.
  3. Useful facts: \(|ab|=|a||b|\), \(-|a|\le a\le|a|\), and \(|x|\lt c\iff -c\lt x\lt c\).
Equality in the triangle inequalityHW1 #4

\(|a+b|=|a|+|b|\iff ab\ge0\).

(⇐) If \(ab\ge0\), then \(a,b\) are both \(\ge0\), both \(\le0\), or one is \(0\). In each case direct computation gives \(|a+b|=|a|+|b|\).

(⇒) Both sides are \(\ge 0\), so square: \(a^2+2ab+b^2=a^2+2|a||b|+b^2\). Hence \(ab=|a||b|=|ab|\), which holds iff \(ab\ge0\). ∎

Family 4

sup / inf proofs

HW2 #1, #3 · HW4 #2 · lecture p.23–24
  1. To prove \(\sup S=M\): (i) \(M\) is an upper bound (\(s\le M\ \forall s\in S\)), and (ii) nothing smaller is: for every \(\varepsilon>0\) find \(s\in S\) with \(s>M-\varepsilon\).
  2. To use a sup you already have: the approximation property gives \(s\in S\) with \(\sup S-\varepsilon\lt s\le\sup S\).
  3. To finish “≥” from “\(>M-m-\varepsilon\) for every \(\varepsilon\)”: if it were strictly smaller, pick \(\varepsilon\) = half the gap and get a contradiction.
  4. For “attained?”: say whether the sup/inf is an element of \(S\) (then it's a max/min).

TrapShowing only the upper-bound half. Both halves are required.

diam(S) = sup S − inf SHW2 #1

Let \(m=\inf S\), \(M=\sup S\) (finite since \(S\) is nonempty and bounded), \(D=\{|s-t|:s,t\in S\}\ni0\).

(≤) For \(s,t\in S\): \(m\le s,t\le M\), so \(s-t\le M-m\) and \(t-s\le M-m\), hence \(|s-t|\le M-m\). So \(M-m\in UB(D)\) and \(\operatorname{diam}S\le M-m\).

(≥) Let \(\varepsilon>0\). Pick \(s_\varepsilon\in S\) with \(M-\frac\varepsilon2\lt s_\varepsilon\) and \(t_\varepsilon\in S\) with \(t_\varepsilon\lt m+\frac\varepsilon2\). Then

\[\operatorname{diam}S\ge|s_\varepsilon-t_\varepsilon|\ge s_\varepsilon-t_\varepsilon>M-m-\varepsilon.\]

If \(\operatorname{diam}S\lt M-m\), take \(\varepsilon=\frac{M-m-\operatorname{diam}S}{2}>0\) for a contradiction. So \(\operatorname{diam}S=M-m\). ∎

S = {x : x⁴ − 5x² + 4 < 0}HW2 #3

\(x^4-5x^2+4=(x^2-1)(x^2-4)\). With \(y=x^2\), \((y-1)(y-4)\lt0\iff1\lt y\lt4\iff1\lt|x|\lt2\).

(a) \(S=(-2,-1)\cup(1,2)\).

(b) \(\inf S=-2\), \(\sup S=2\). Neither is attained (\(\pm2\notin S\) because the inequality is strict), so \(S\) has no min and no max.

Build aₙ ↑ α = sup A with 0 < α − aₙ < 2⁻ⁿHW4 #2

Key fact. For every \(t\lt\alpha\) there is \(a\in A\) with \(t\lt a\le\alpha\) (otherwise \(t\) is a smaller upper bound). Since \(\alpha\notin A\), in fact \(t\lt a\lt\alpha\).

Construction. Choose \(a_1\in A\) with \(\alpha-2^{-1}\lt a_1\lt\alpha\). Given \(a_n\), let \(t_n=\max\{a_n,\ \alpha-2^{-(n+1)}\}\lt\alpha\) and choose \(a_{n+1}\in A\) with \(t_n\lt a_{n+1}\lt\alpha\). Then

\[a_{n+1}>a_n,\qquad 0\lt\alpha-a_{n+1}\lt2^{-(n+1)}.\]

Limit. \(0\le|a_n-\alpha|\lt2^{-n}\) and \(2^{-n}\to0\), so by Squeeze \(a_n\to\alpha\). ∎

The max in t_n is what makes it strictly increasing AND close to α at the same time.

Family 5

Archimedean property + well-ordering

HW2 #2 · lecture p.07, p.26
  1. Existence: define the set of “good” naturals. Archimedean shows it's nonempty; well-ordering gives its least element.
  2. Minimality of that element gives the other inequality.
  3. Uniqueness: assume two, say \(m\lt n\), use \(m\le n-1\) for integers, and get a contradiction.
Unique n with n − 1 ≤ a < nHW2 #2

Fix \(a>0\). Let \(A=\{k\in\mathbb{N}:a\lt k\}\). By Archimedean, \(A\ne\emptyset\). By well-ordering, \(A\) has a least element \(n\), so \(a\lt n\).

If \(n=1\): \(n-1=0\le a\). If \(n>1\): \(n-1\in\mathbb{N}\) and \(n-1\notin A\) by minimality, so \(n-1\le a\). This proves existence.

Uniqueness. Suppose \(m,n\) both work and \(m\lt n\). Then \(m\le n-1\), so \(a\lt m\le n-1\le a\), a contradiction. Symmetric for \(n\lt m\). So \(m=n\). ∎

Family 6

ε–N proof of a limit

HW2 #5 · lecture p.34–37
  1. Scratch (not graded): simplify \(|s_n-L|\) to one fraction. Drop the absolute value once you know the sign.
  2. Bound it by something simple like \(\frac{C}{n}\). Make the numerator bigger (e.g. \(3n+17\le20n\) since \(n\ge1\)) and the denominator smaller (drop positive terms).
  3. Solve \(\frac{C}{n}\lt\varepsilon\): that gives \(N=\frac{C}{\varepsilon}\). If a step needed “\(n\) large enough”, use \(N=\max\{\frac{C}{\varepsilon},\,\text{that threshold}\}\).
  4. Write-up: “Let \(\varepsilon>0\). Choose \(N\) … Let \(n>N\).” Then one chain of (in)equalities ending in \(\lt\varepsilon\).

TrapNo limit laws allowed inside an ε–N proof, and don't write the chain backwards (starting from \(\lt\varepsilon\)).

lim (3n² − 1)/(2n² + n + 5) = 3/2HW2 #5

Scratch. \(\left|\frac{3n^2-1}{2n^2+n+5}-\frac32\right|=\frac{|2(3n^2-1)-3(2n^2+n+5)|}{2(2n^2+n+5)}=\frac{3n+17}{4n^2+2n+10}\le\frac{3n+17}{4n^2}\le\frac{20n}{4n^2}=\frac5n.\)

Proof. Let \(\varepsilon>0\). By the Archimedean Property choose \(N\in\mathbb{N}\) with \(N>\frac5\varepsilon\). Let \(n\ge N\). Since \(n\ge1\), \(3n+17\le20n\), so

\[\left|\frac{3n^2-1}{2n^2+n+5}-\frac32\right|=\frac{3n+17}{4n^2+2n+10}\le\frac{3n+17}{4n^2}\le\frac{20n}{4n^2}=\frac5n\le\frac5N\lt\varepsilon.\ \blacksquare\]
Lecture version with a “large enough” stepp.36–37

\(\lim\frac{4n^2+3n}{n^2-6}=4\).

\(\left|\frac{4n^2+3n}{n^2-6}-4\right|=\frac{3n+24}{n^2-6}\) for \(n\ge3\). For \(n>1\): \(3n+24\lt27n\). For \(n>4\): \(n^2-6>\frac12n^2\). So the error is \(\lt\frac{27n}{\frac12n^2}=\frac{54}{n}\).

Proof. Let \(\varepsilon>0\), \(N:=\max\{\frac{54}\varepsilon,12\}\). Let \(n>N\). Then \(\frac{3n+24}{n^2-6}\lt\frac{27n}{n^2-6}\lt\frac{27n}{\frac12n^2}=\frac{54}{n}\lt\varepsilon.\) ∎

The 12 is only there to make the “n large enough” steps true. Any big number works.

(11n⁶ − 4n⁵ + 9n² − 7)/(13n⁶ + 5n⁴ + 2n + 1) → 11/13HW3 #1

By \(n^{-p}\to0\) with the scalar-multiple and Sum rules: \(A_n\to11\), \(B_n\to13\).

For every \(n\), all non-constant terms of \(B_n\) are positive, so \(B_n>13>0\). And \(\lim B_n=13\ne0\). Both Quotient Rule hypotheses hold, so the limit is \(\frac{11}{13}\). ∎

xₙ → −2, yₙ → 5: lim (2yₙ − xₙ)/(xₙ + 2yₙ)²HW3 #2

Given \(x_n+2y_n\ne0\), the square is \(\neq0\) for every \(n\), and its limit \(64\ne0\). Quotient Rule: the limit is \(\frac{12}{64}=\frac{3}{16}\). ∎

uₙ = (aₙ⁴ − 2aₙbₙ + 3)/(aₙ² + bₙ² + 1)HW3 #3

Scalar/Sum/Difference: \(A_n:=a_n^4-2a_nb_n+3\to a^4-2ab+3\) and \(B_n:=a_n^2+b_n^2+1\to a^2+b^2+1\).

Quotient conditions. Squares are \(\ge0\), so \(B_n\ge1>0\) for every \(n\), and \(a^2+b^2+1\ge1>0\). So the Quotient Rule applies: \(\lim u_n=\dfrac{a^4-2ab+3}{a^2+b^2+1}\). ∎

aₙ = (2n³ + n)/(n³ − 5)HW2 #4a

Limits equal to +∞

HW3 #4, #5
  1. Write the definition: for every \(M\in\mathbb{R}\) find \(N\) with \(n>N\Rightarrow s_n>M\).
  2. Get a simple lower bound by induction (e.g. \(x_n\ge3^{n-1}\ge n\)), then choose \(N>M\).
  3. When combining with another limit, use a tolerance like \(\varepsilon=1\) and threshold \(M+1\), then take \(N=\max\) of all the \(N\)s.

TrapDon't use “3ⁿ → ∞” as a known fact unless it's been proved. The solution proves \(3^{n-1}\ge n\) by induction.

x₁ = 1, xₙ₊₁ = 4xₙ² − xₙ → +∞HW3 #4

Step 1: \(x_n\ge3^{n-1}\) by induction. \(x_1=1=3^0\). If \(x_n\ge3^{n-1}\ge1\), then \(4x_n-1\ge3\) and \(x_n>0\), so \(x_{n+1}=x_n(4x_n-1)\ge3x_n\ge3^n\).

Step 2: \(3^{n-1}\ge n\) by induction. True at \(n=1\). If \(3^{n-1}\ge n\), then \(3^n\ge3n\ge n+1\).

Step 3. Let \(M\in\mathbb{R}\). Choose an integer \(N>M\). For \(n>N\): \(x_n\ge3^{n-1}\ge n>N>M\). So \(x_n\to+\infty\). ∎

sₙ ≤ tₙ + rₙ, rₙ → 0, sₙ → +∞ ⇒ tₙ → +∞HW3 #5

Let \(N=\max\{N_0,N_1,N_2\}\). For \(n>N\):

\[t_n\ge s_n-r_n\ge s_n-|r_n|>s_n-1>M.\]

\(M\) was arbitrary, so \(t_n\to+\infty\). ∎

Monotone recursive sequence

HW4 #3 · lecture p.51–52
  1. Bounds by induction. Show the terms stay in an interval (and the recurrence is defined, e.g. the denominator is \(>0\)).
  2. Monotone. Compute \(x_{n+1}-x_n\) (or \(x_{n+1}^2-x_n^2\)) as a single factored expression and read its sign off the bounds.
  3. Converges by the Monotone Convergence Theorem. Call the limit \(\ell\).
  4. Only now take limits in the recurrence (both \(x_{n+1}\to\ell\) and \(x_n\to\ell\)), solve for \(\ell\), and use the bounds (order limit corollary) to pick the right root.

TrapSolving \(\ell=f(\ell)\) before proving convergence is the “false argument” from p.47. It loses most of the credit.

x₁ = 4, xₙ₊₁ = (3xₙ + 4)/(xₙ + 3)HW4 #3

Step 1. Claim: \(x_n\) is defined and \(2\lt x_n\le4\). True for \(n=1\). If \(2\lt x_n\le4\), then \(x_n+3>0\) so \(x_{n+1}\) is defined, and

\[x_{n+1}-2=\frac{x_n-2}{x_n+3}>0,\qquad x_{n+1}-x_n=\frac{4-x_n^2}{x_n+3}\lt0.\]

So \(2\lt x_{n+1}\lt x_n\le4\). This completes the induction and shows \((x_n)\) is strictly decreasing.

Step 2. Decreasing and bounded below by 2, so by MCT \(x_n\to\ell\) with \(\ell\in[2,4]\). Now \(x_n+3\to\ell+3\ge5\ne0\), so by the Quotient Rule \(\ell=\frac{3\ell+4}{\ell+3}\). Then \(\ell^2=4\), and \(\ell\ge2\) rules out \(-2\). So \(\lim x_n=2\). ∎

x₁ = 1, xₙ₊₁ = √(6 + xₙ)lecture p.51

Bounds: \(1\le x_1\le3\). If \(1\le x_k\le3\), then \(7\le6+x_k\le9\), so \(1\le\sqrt7\le x_{k+1}\le3\).

Increasing: \(x_{n+1}^2-x_n^2=6+x_n-x_n^2=(x_n+2)(3-x_n)\ge0\), so \(x_{n+1}\ge x_n\).

MCT gives \(x_n\to L\). Then \(L=\sqrt{6+L}\), so \(L\in\{-2,3\}\), and \(1\le L\le3\) forces \(L=3\). ∎

Family 10

Cauchy sequences

HW4 #1 · lecture p.58–60
  1. For \(m>n\), telescope: \(|s_m-s_n|\le\sum_{k=n}^{m-1}|s_{k+1}-s_k|\).
  2. Bound the finite sum with a finite geometric sum: \(\sum_{k=n}^{m-1}2^{-k}=2^{1-n}(1-2^{-(m-n)})\le2^{1-n}\).
  3. Pick \(N\) so the bound is \(\lt\varepsilon\). Say that \(m=n\) is trivial and \(n>m\) is symmetric.
  4. Completeness of ℝ gives a limit \(L\). For an error bound, fix \(n\) and let \(m\to\infty\) in \(|s_n-s_m|\le\) bound.
|sₙ₊₁ − sₙ| ≤ 1/(n·2ⁿ) ⇒ Cauchy, |sₙ − L| ≤ 1/(n·2ⁿ⁻¹)HW4 #1

For \(m>n\ge1\), using \(\frac1k\le\frac1n\) for \(k\ge n\):

\[|s_m-s_n|\le\sum_{k=n}^{m-1}|s_{k+1}-s_k|\le\sum_{k=n}^{m-1}\frac1{k2^k}\le\frac1n\sum_{k=n}^{m-1}2^{-k}=\frac{1}{n2^{n-1}}\left(1-2^{-(m-n)}\right)\le\frac1{n2^{n-1}}.\]

Cauchy. Given \(\varepsilon>0\), choose \(N\in\mathbb{N}\) with \(\frac1N\lt\varepsilon\). For \(m>n\ge N\) the bound is \(\le\frac1n\le\frac1N\lt\varepsilon\). The case \(n>m\) is symmetric and \(m=n\) is immediate. By completeness of ℝ, \(s_n\to L\in\mathbb{R}\).

Error bound. Fix \(n\). For all \(m>n\), \(|s_n-s_m|\le\frac1{n2^{n-1}}\). Let \(m\to\infty\): \(|s_n-L|=\lim_m|s_n-s_m|\le\frac1{n2^{n-1}}\). ∎

Subsequences and divergence

HW2 #4b · HW4 #4, #5 · lecture p.61–64
  1. To show divergence: write down two subsequences (usually even and odd indices), compute each limit, and cite the Corollary on p.63 (different limits ⇒ diverges).
  2. Justify that they are subsequences: the index maps \(k\mapsto2k\), \(k\mapsto2k-1\) are strictly increasing.
  3. To build a subsequence with a property: apply the definition once for each \(j\) (with \(\varepsilon=2^{-j}\) or \(1/j\)), then force the indices up with \(\max\{\cdot,\text{previous}+1\}\).
bₙ = (−1)ⁿ n/(n + 1)HW2 #4b

\(b_{2k}=\frac{2k}{2k+1}\to1\) and \(b_{2k+1}=-\frac{2k+1}{2k+2}\to-1\). Two subsequences with different limits, so \((b_n)\) diverges.

aₙ = 2 + (−1)ⁿ + (1 + (−1)ⁿ)/nHW4 #4

Odd indices (constant): \(a_{2k-1}=2-1+\frac{0}{2k-1}=1\) for all \(k\), so it converges to 1.

Even indices (nonconstant): \(a_{2k}=3+\frac{2}{2k}=3+\frac1k\to3\). It's nonconstant since \(3+\frac1{k+1}\lt3+\frac1k\).

\(k\mapsto2k-1\) and \(k\mapsto2k\) are strictly increasing, so both are subsequences. If \((a_n)\) converged, every subsequence would have the same limit (Thm 1). Since \(1\ne3\), \((a_n)\) does not converge. ∎

Refine σ to τ with |s_{σ(τ(j))} − L| < 2⁻ʲHW4 #5

For each \(j\), apply \(s_{\sigma(k)}\to L\) with \(\varepsilon=2^{-j}\): there is \(K_j\) with \(k\ge K_j\Rightarrow|s_{\sigma(k)}-L|\lt2^{-j}\).

Define \(\tau(1)=K_1\), \(\tau(j+1)=\max\{K_{j+1},\ \tau(j)+1\}\). Then \(\tau(j)\ge K_j\) (so \(|s_{\sigma(\tau(j))}-L|\lt2^{-j}\)) and \(\tau(j+1)>\tau(j)\) (so \(\tau\) is strictly increasing).

Composition. If \(i\lt j\) then \(\tau(i)\lt\tau(j)\), and since \(\sigma\) is strictly increasing, \(\sigma(\tau(i))\lt\sigma(\tau(j))\). So \(\sigma\circ\tau\) is strictly increasing, which makes \((s_{\sigma(\tau(j))})\) a subsequence of \((s_n)\). Its error is \(\lt2^{-j}\to0\), so it converges to \(L\). ∎

Family 12

liminf / limsup

HW5 #1, #2 · lecture p.53–57, p.68–74
  1. To compute: split the sequence into the obvious subsequences (by residue mod 2, 3, 4…). Find each one's limit in \(\overline{\mathbb{R}}\).
  2. Argue these are the only subsequential limits: any subsequence has infinitely many terms from one class, and that piece converges to that class's limit.
  3. Then \(\liminf=\min S(s_n)\) and \(\limsup=\max S(s_n)\) (p.68). The sequence has a limit in \(\overline{\mathbb{R}}\) iff they're equal (p.55).
  4. With a convergent add-on like \(\frac1n\), use the p.73 theorem: \(\limsup(a_n+b_n)=a+\limsup b_n\).
  5. To prove inequalities: work with tails. Fix \(N\), compare \(\sup\{a_n:n\ge N\}\) with \(\sup\{b_n:n\ge N\}\), then let \(N\to\infty\).

Trapliminf/limsup can be ±∞. A sequence that is unbounded above has limsup = +∞, and that is a valid answer.

s₃ₖ₋₂ = −2 + 1/k, s₃ₖ₋₁ = 1 − 1/k, s₃ₖ = kHW5 #1

My solution, no official one posted

Three subsequences. The index maps \(k\mapsto3k-2,\ 3k-1,\ 3k\) are strictly increasing, and

\[s_{3k-2}=-2+\tfrac1k\to-2,\qquad s_{3k-1}=1-\tfrac1k\to1,\qquad s_{3k}=k\to+\infty.\]

So \(-2,\,1,\,+\infty\in S(s_n)\).

No others. Let \((s_{n_j})\) be any subsequence with \(s_{n_j}\to t\in\overline{\mathbb{R}}\). Infinitely many of the \(n_j\) lie in one of the three classes \(\{3k-2\}\), \(\{3k-1\}\), \(\{3k\}\). Those terms form a subsequence of \((s_{n_j})\), so they still tend to \(t\) (Thm 1). They also form a subsequence of the corresponding class, so they tend to \(-2\), \(1\), or \(+\infty\). By uniqueness, \(t\in\{-2,1,+\infty\}\). Hence

\[S(s_n)=\{-2,\ 1,\ +\infty\}.\]

liminf/limsup. \(\liminf s_n=\min S(s_n)=-2\) and \(\limsup s_n=\max S(s_n)=+\infty\).

Check with tails: every tail contains −2 + 1/k for arbitrarily large k and nothing below −2, so u_N = −2. Every tail is unbounded, so v_N = +∞.

Limit? \(\liminf s_n=-2\neq+\infty=\limsup s_n\), so by p.55 \((s_n)\) has no limit in \(\overline{\mathbb{R}}\). ∎

aₙ ≤ bₙ + rₙ eventually, rₙ ≥ 0, rₙ → 0 ⇒ liminf/limsup inequalitiesHW5 #2

My solution, no official one posted

Setup. Since \((a_n),(b_n)\) are bounded, every tail sup and inf is a real number. Write

\[u_N=\inf_{n\ge N}a_n,\quad v_N=\sup_{n\ge N}a_n,\quad u_N'=\inf_{n\ge N}b_n,\quad v_N'=\sup_{n\ge N}b_n.\]

Let \(\varepsilon>0\). There is \(N_0\) with \(a_n\le b_n+r_n\) for \(n\ge N_0\), and since \(r_n\to0\) there is \(N_1\) with \(r_n\lt\varepsilon\) for \(n\ge N_1\). Let \(N'=\max\{N_0,N_1\}\). Then

\[a_n\lt b_n+\varepsilon\qquad\text{for all } n\ge N'.\tag{★}\]

limsup. Fix \(N\ge N'\). For every \(n\ge N\), (★) gives \(a_n\lt b_n+\varepsilon\le v_N'+\varepsilon\). So \(v_N'+\varepsilon\) is an upper bound of \(\{a_n:n\ge N\}\), hence \(v_N\le v_N'+\varepsilon\). Letting \(N\to\infty\) (order limit theorem): \(\limsup a_n\le\limsup b_n+\varepsilon\).

liminf. Fix \(N\ge N'\). For every \(n\ge N\), \(u_N\le a_n\lt b_n+\varepsilon\), so \(u_N-\varepsilon\lt b_n\). Thus \(u_N-\varepsilon\) is a lower bound of \(\{b_n:n\ge N\}\), hence \(u_N-\varepsilon\le u_N'\). Letting \(N\to\infty\): \(\liminf a_n\le\liminf b_n+\varepsilon\).

Remove ε. Both hold for every \(\varepsilon>0\). If \(x\le y+\varepsilon\) for all \(\varepsilon>0\) then \(x\le y\) (otherwise take \(\varepsilon=\frac{x-y}{2}\)). So \(\liminf a_n\le\liminf b_n\) and \(\limsup a_n\le\limsup b_n\). ∎

Periodic (1,2,3,4,…) + 1/nlecture p.74

\(a_n=(1,2,3,4,1,2,3,4,\dots)\), \(s_n=a_n+\frac1n\). Since \(\frac1n\to0\), the p.73 theorem gives \(\liminf s_n=\liminf a_n+0=1\) and \(\limsup s_n=\limsup a_n+0=4\).
